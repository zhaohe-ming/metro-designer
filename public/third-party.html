在线服务

  • OpenStreetMap 与 CARTO：默认免配置地理瓦片底图与导出底图拼接能力，地图版权归 OpenStreetMap 贡献者及相关图源所有。
  • 高德开放平台：可选服务。当用户在本地自行配置个人高德 Web 端（JS API）Key 与安全密钥（或部署配置静态图服务）时，加载高德矢量底图并保留高德官方署名与审图信息。
  • DeepSeek 及用户自选兼容模型服务商：调用 AI 助手或站名翻译时处理指令及必要的线网上下文；用户自填 API Key 保存在本机浏览器，调用时经本站后端即时转发，服务端不落盘存储。
  • Resend：部署启用时发送注册验证和找回密码邮件。
  • Vercel、Render：网页与后台部署基础设施。

开源组件

主要使用 React、React DOM、Ant Design、Ant Design Icons、Konva、React Konva 等组件。Windows 客户端使用 Electron，安卓客户端使用 AndroidX WebKit。相关版权及开源许可归各权利人所有。
