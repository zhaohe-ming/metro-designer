隐私与数据说明

更新日期：2026年11月26日 · 适用于网页版及在线客户端

本页介绍 Metro Designer 当前功能涉及的数据及用途。隐私与账号问题请联系 3855166698@qq.com。

账号与登录

注册、邮箱验证和找回密码需要你的邮箱及登录密码。昵称和头像由你自行设置；历史账号可能保留此前提供的手机号。后端使用密码散列验证登录。登录凭证保存在当前浏览器或客户端的本地存储中，退出登录会清除当前登录凭证。

免登录预览与本机草稿

你可以免登录体验示例线网并编辑。当前预览草稿（线路、站点、区间、视图、样式及专业运营配置）保存在此浏览器或客户端的 IndexedDB 中，用于刷新后继续编辑。清理网站数据、卸载应用或更换设备后，本机草稿可能丢失；可下载备份或登录保存到云端。只有主动登录并保存时，这份草稿才会与账号关联并上传云端。网页、Windows 及 Android 客户端各自保存本机草稿。

地图与作品

线路、站点、区间、坐标、作品名称、样式及专业运营方案等数据用于绘制、时刻表推演及展示。选择云端保存后，相关作品与账号关联并存入后台。导出的图片、视频及数据文件通过浏览器或客户端的保存功能交给你管理。删除已保存作品会删除对应的在线记录；建议先导出需要保留的内容。

作品广场

主动提交并通过审核后，作品的公开副本、封面、标题、简介、昵称和头像可被访客浏览；站点备注默认保留在私人原稿内，由你在发布时选择是否公开。允许复制再创作时，访客可将公开线网复制到本机草稿或自己的云端地图，复制来源会随作品保存。点赞、收藏、提交记录和举报反馈与账号关联，用于展示互动和处理内容反馈。你可以撤回自己的公开作品；已被他人复制的副本由对方独立保存。删除私人原稿后，其此前发布的公开副本继续保留，请在“我的作品”中单独撤回。

地图、邮件、AI 与本地自有密钥说明

  • 地理底图默认使用公开地图瓦片服务（OpenStreetMap / CARTO，部分请求经本站瓦片缓存代理加载以支持离线/导出合成）；当你在地图设置中自行配置个人高德 Web 端（JS API）Key 与安全密钥时，密钥仅保存在当前浏览器或客户端的本地存储（localStorage）中，由你的终端浏览器直接向高德开放平台发起地图加载请求，绝不写入本站后台数据库。使用真实经纬度绘图时，请留意作品中的位置内容。
  • 部署启用 Resend 邮件服务时，注册邮箱及验证、找回密码邮件交由该服务发送。
  • 使用平台免费 AI 通道时，输入的指令及完成编辑所需的线网上下文会发送至 DeepSeek 接口。当你在「AI 接口设置」中开启并填写自有 API Key 时，该密钥仅保存在当前浏览器或客户端本地存储中，绝不写入本站数据库；仅在你主动发起 AI 编辑、站名翻译或连接测试时，随当次 HTTPS 请求头经本站后端即时转发至你所选的模型服务商（如 DeepSeek、硅基流动、通义百炼、Kimi 或 OpenAI 兼容端点）完成调用，请求结束后服务端不留存你的密钥。
  • 网页与后台运行涉及 Vercel、Render 等基础设施，网络和后台数据由实际部署节点处理。相关服务说明见第三方服务与开源许可。

本地偏好与权限

主题、语言、侧栏比例及上次底图风格等偏好保存在本地，用于恢复操作习惯。安卓客户端通过系统文件选择器处理导入和导出；当前安装包声明网络权限。第三方底图会按自身规则处理必要网络信息。

保存、访问与删除申请

账号资料和已保存作品用于维持你的账号及云端作品。你可以修改昵称、头像，管理或删除云端地图，并导出自己的作品。账号注销及相关数据访问、更正、导出或删除申请，请通过注册邮箱联系 3855166698@qq.com，注明请求类型；请在邮件中保留必要信息并妥善保管密码。核实账号归属后，我们会回复处理方式及涉及的保留事项。
