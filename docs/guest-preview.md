# 免登录预览 · 2026-11-22

入口：登录页“免登录预览”，或 `https://www.metro-designer.com/?preview=1`。

## 用户流程

首次展示三条虚构线路、12个站点、两个换乘点。可直接修改或确认后重新开始空白方案；空白方案继续提供新建线路和四种高德底图风格。

访客可编辑线网、调整主题与视图、撤销重做、导出示意图 PNG、观看动态示例。AI、云端地图与自定义视频导出通过登录弹窗继续，关闭弹窗保留文档。原登录、注册、找回密码及邮箱验证流程复用现有组件。

本机草稿只有一份，保存到当前浏览器/客户端的 IndexedDB；刷新时恢复文档、当前线路、地图设置及纯画布视图。登录弹窗在工作台之上，现有编辑历史保持在内存中；整页刷新恢复文档并重新开始撤销历史。清理站点数据或更换设备会影响本机草稿，支持下载 JSON 备份。读失败时避免自动覆盖旧数据，并提供重试及备份入口。

点击“登录并保存”后，认证成功继续保存命名。云端确认成功后清除访客会话标记和本机迁移草稿；后续保存走原覆盖保存。若上传失败，草稿继续保留。登录和验证期间抑制旧云端地图自动覆盖草稿。

## 数据与兼容性

- `src/lib/guestDraft.ts`：示例图、IndexedDB读写队列、独立访客标记。
- `clientDraftId` 为可选创建参数。服务端用账号ID与草稿ID的 SHA-256 构造稳定地图ID；PostgreSQL通过主键 upsert，JSON存储复用同一ID，重试不会重复建图。原请求无需变动，无数据库结构迁移。
- 作品云端保存和全部业务API仍保留原JWT和账号归属校验，高德静态图片代理继续要求登录。
- Windows和Android在线客户端加载同一正式站点，重启/刷新后获取界面更新，本轮安装包版本保持原值。各端的本机草稿相互独立，登录保存后通过账号访问云端。
- 隐私说明同步补充本机草稿的保存、清理和上传时机。

## 验证

`node scripts/verify-guest-import.cjs` 使用临时JSON数据库和随机本地端口，验证匿名请求拒绝、幂等重试、最新内容、账号隔离和普通登录/保存。`--serve` 用于浏览器验收，数据仅写到 Git 忽略的 `outputs/guest-preview/fixture-data`，请指定 `GUEST_TEST_PORT`。
