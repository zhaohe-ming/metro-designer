# 移动端操作改进 · 2026-11-17

## 使用方式

- 顶部工具显示选择、站点、连线、区间、移动五个名称，切换后展示短提示。
- 手机顶部工具采用一体磨砂胶囊与共享蓝色滑块；320px 下按 51px 按钮宽度对齐。仅对位移做过渡，降低动效时直接切换；高德底图下提高面板不透明度，不支持磨砂时使用实色回退。桌面工具栏保留原样。
- 在手机顶部工具栏按住并横向拖动，蓝色选中块连续跟手预览，松手吸附到最近工具并确认一次。点按和键盘激活继续可用。壳体随按压及滑动速度轻微拉伸，两端最多偏移 4px，释放后弹簧回正；工具栏保持固定位置。
- 工具栏手势使用 Pointer Events 和指针捕获，与画布导航隔离。从栏体开始后，纵向移出仍保持拖动，预览与释放均仅按 X 坐标计算；松手使用最终 X 直接确认，无需等待滑块追上手指，两端之外吸附至首尾工具。系统取消、指针捕获丢失、第二个触点、失焦、屏幕尺寸变化、Escape 均撤回预览。高频状态保存在 ref，仅写 CSS 变量，松手时更新画布工具状态；模糊强度保持恒定。降低动态效果时保留拖动和吸附，关闭拉伸与回弹。
- 移动工具：单指拖动画布。任意工具：双指平移、以双指中心缩放；一指离开后继续导航，全部离屏后恢复编辑。
- 选择工具：点站点打开底部编辑面板，拖动站点调整位置。站点与区间长按 550ms 也可打开编辑菜单。
- 站点面板直接提供加入线路、指定连接站、仅加入、详情标注、重命名、删除和取消。
- 点区间可打开途经点管理，通过“调整区间走向”进入放置流程。画布提示当前待放置状态，支持取消。
- 手机底部合为一条磨砂胶囊栏，顺序为撤销、重做、缩小、缩放比例、放大、视图菜单、导出。视图菜单提供适应视图与重置视图；导出保留文字及图片/演示视频两个入口。各项共用外层边框，按钮无独立框，触控高度 44px，保留键盘焦点提示。
- 320px 下压缩图标按钮宽度，维持单行且不出现横向滚动；手机横屏时胶囊居中并限制至 500px，线路侧栏展开时整条底栏隐藏。桌面继续使用原有顶部文档操作与右下角缩放 HUD。
- 安卓 APP 的账号菜单隐藏“下载客户端”，安卓浏览器保留下载入口；复用原生 `MetroDesignerAndroid/版本号` 标识识别。各端“关于我们”包含版本、更新记录、独立产品说明及联系邮箱，账号与数据链接到个人中心。
- 缩放按钮、百分比和适应视图统一提交实际视图，缩放以视口中心为锚点。适应视图为站名、工具和底部操作预留空间。
- 手机命令输入栏收起；桌面保留。小屏线路侧栏为抽屉，关闭时隐藏其可访问内容。
- 移动端线路抽屉采用不透明底色：亮色主题为白底，暗色主题沿用深色面板。展开时隐藏整条缩放 HUD，收起后恢复。
- 空白画布中央提供“新建线路”和“导入高德底图”。320px 窄屏按两行排列；手机横屏压缩插画与留白，避开工具栏及底部操作。开始创建内容或切换底图后提示收起。
- 空白画布上方的小线网在图片加载完成后淡入并轻微上浮，复用登录页的 auth-brand-rise 与缓动曲线，延迟 120ms、持续 800ms；网页、Windows 和安卓共用同一组件。重新进入空白提示时播放一次，降低动态效果时直接显示，图片固有空间保持固定。
- 高德入口先选择四种底图风格，确认后开始绘制；手机采用底部选择面板，竖屏两列、横屏四列。取消保留原图，上次选择在本地记忆。
- 底图选项统一使用四边 2px 的单层边框；选中仅变色，取消卡片焦点外框与额外阴影，键盘焦点保留在单选圆点上。

## 实现范围

沿用 CRA、React、TypeScript、Ant Design、Konva；未添加依赖。界面、手势与视图操作在前端完成，账号、云端保存、服务端 API 和 Windows 安装包保持现有流程。

`src/lib/touchViewport.ts` 使用独立手势状态记录触点 ID、位移、双指接管和点击资格。触点数组顺序变化、双指变单指、拖动、长按和系统取消均有明确处理。高频视图更新直接写 Stage 并 batchDraw，结束后同步 React 状态；节点拖拽只在双指接管时终止一次。

参考官方行为：

- Konva 双指手势与拖动命中：https://konvajs.org/docs/sandbox/Multi-touch_Scale_Stage.html
- 高德 JS API 的立即缩放和容器投影：https://a.amap.com/jsapi/static/doc/20230922/index.html
